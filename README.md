# AI Chat Exporter (Userscript)

Ein einfaches und datenschutzfreundliches **Tampermonkey-Skript**, mit dem du Gespräche von ChatGPT, Claude, Gemini, Grok und anderen KI-Plattformen exportieren kannst.

## Features

- Exportiert komplette Chats als **Markdown** (.md)
- Erhält Formatierung (Code-Blöcke, Tabellen, Überschriften, fett/kursiv)
- Funktioniert lokal im Browser – **keine Daten verlassen deinen Rechner**
- Unterstützt ChatGPT, Claude, Gemini, Grok und weitere Plattformen
- Einfacher Export-Button direkt im Chat
- Open Source und frei anpassbar

## Installation

1. Installiere die Erweiterung **[Tampermonkey](https://addons.mozilla.org/de/firefox/addon/tampermonkey/)** (Firefox) oder die entsprechende Version für deinen Browser.
2. Klicke auf den folgenden Link, um das Skript zu installieren:  
   **[Skript installieren](https://raw.githubusercontent.com/dein-benutzername/dein-repo-name/main/ai-chat-exporter.user.js)**  
   *(Ersetze `dein-benutzername` und `dein-repo-name` durch deine echten GitHub-Daten)*
3. Bestätige die Installation in Tampermonkey.

## So wird es benutzt

1. Öffne einen Chat bei ChatGPT, Claude, Gemini, Grok oder einer anderen unterstützten Plattform.
2. Ein **Export-Button** erscheint automatisch (meist unten rechts oder oben).
3. Klicke auf den Button und wähle „Export as Markdown“.
4. Die Datei wird automatisch heruntergeladen.

## Unterstützte Plattformen

- ChatGPT (chatgpt.com)
- Claude (claude.ai)
- Gemini (gemini.google.com)
- Grok (grok.x.ai / x.com)
- Weitere können bei Bedarf hinzugefügt werden

## Datenschutz

- Alles läuft **100 % lokal** im Browser.
- Es werden **keine** Daten an externe Server gesendet.
- Der Quellcode ist öffentlich einsehbar.
